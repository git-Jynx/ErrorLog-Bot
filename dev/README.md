# dev/ — 개발·검증용 도구

이 폴더에는 **봇을 만들고 고치는 사람이 쓰는 도구**가 들어 있습니다.
봇을 설치해 쓰기만 하는 분은 이 폴더를 열 일이 없습니다.

## add_test_pending.py

저장에 실패한 기록을 담아 두는 백업 파일(`pending_records.json`)에
테스트용 기록 1건을 넣습니다. 봇을 다시 켤 때 뜨는 재시작 알림과
`[🔄 지금 저장]` · `[🗑 버리기]` 버튼이 제대로 동작하는지 확인하는 용도입니다.

노션 저장 실패를 일부러 만들어 내기가 어려우므로, 실패한 것과 똑같은 상태를
직접 만들어 줍니다. **이 스크립트 자체는** `.env`와 노션에 아무것도 쓰지 않습니다.

프로젝트 루트에서 실행합니다.

**맥 / 리눅스**

```bash
.venv/bin/python dev/add_test_pending.py
```

**윈도우 (PowerShell)**

```powershell
.venv\Scripts\python dev/add_test_pending.py
```

넣은 테스트 기록을 없애려면 `pending_records.json`의 내용을 `[]`로 되돌리거나,
봇 재시작 알림에서 `[🗑 버리기]` → 확인 화면의 `[🗑 네, 버립니다]`를 누르면 됩니다.
`[🗑 버리기]`만 눌러서는 지워지지 않습니다.

### ⚠️ `[🔄 지금 저장]`을 누르면 노션에 실제 페이지가 생깁니다

재시작 알림에서 `[🔄 지금 저장]`을 누르면 **노션에 테스트 기록이 진짜로
저장됩니다.** 문제위치가 `TEST_복구확인`인 페이지가 그것입니다.
확인이 끝나면 **노션에서 직접 지우셔야 합니다.** 봇이 지워 주지 않습니다.

### ⚠️ 없는 선택지는 노션에 새로 만들어집니다

이 스크립트가 넣는 값(`과목`·`단원`·`개념태그`·`지식유형`)이 내 노션 표의 선택지에
없으면, 저장할 때 **노션이 그 선택지를 새로 만듭니다.** 봇은 값을 허용 목록과
대조하지 않고 그대로 보내기 때문입니다(`docs/notion_template_spec.md` §8).

내 표의 선택지와 다르다면, 실행하기 전에 `add_test_pending.py`의 `TEST_DATA`를
내 표에 있는 값으로 고치세요. 잘못 만들어진 선택지는 노션에서 지우면 됩니다.
