# CPA 오답노트 정리 봇 📘

**텔레그램으로 오답을 보내면, 정리된 기록이 노션에 자동으로 쌓이는 개인용 오답 관리 봇입니다.**

공부하다 틀린 문제를 정리하려고 하면, 정작 공부보다 **어떤 과목인지, 어떤 개념인지 분류하고 어디에 기록할지 정리하는 과정**에 시간이 들곤 합니다. 이 봇은 그 과정을 간단하게 만들었습니다.
텔레그램에서 `/new`를 입력하고 과목·단원·개념 태그를 버튼으로 선택한 뒤, 오답 내용을 붙여넣으면 됩니다. 수식과 코드블록을 포함한 내용은 노션 페이지로 자동 저장되며, 같은 개념을 이전에 몇 번 틀렸는지도 함께 확인할 수 있습니다. 시험 전에는 `/export`를 통해 원하는 범위의 오답 기록을 하나의 정리본으로 모아볼 수 있습니다.

## 🛠 1. 준비물

### 1-1. 먼저 실행 경로를 고르세요

이 프로그램을 내 컴퓨터에서 돌리는 방법이 두 가지 있습니다. **어느 쪽을 골라도
봇의 기능과 결과는 완전히 같습니다.** 설치하는 프로그램의 개수만 다릅니다.

| 항목 | 경로 A: OS 기본 터미널 | 경로 B: VS Code |
| --- | --- | --- |
| 설치할 것 | 파이썬만 | 파이썬 + VS Code |
| 난이도 | 설치할 프로그램이 하나뿐입니다. 이 봇은 설치가 끝나면 텔레그램에서만 쓰고, 직접 손대는 파일이 `.env`와 `chapters.yaml` 두 개뿐이라 이 경로로 충분합니다 | 프로그램을 하나 더 설치해야 하지만, 프로젝트 폴더 안의 파일이 목록으로 보여 파일을 찾고 고치기가 편합니다 |
| 이런 분께 | 설치해서 쓰기만 할 분 | 코드를 직접 고쳐볼 생각이 있는 분 |

**고르는 기준:** 지금 컴퓨터에 VS Code가 깔려 있지 않고, 앞으로 코드를 고칠 생각도
없다면 **경로 A**를 고르세요. 이 문서는 §4부터 두 경로를 따로 적어 두었으니,
고른 쪽만 읽으면 끝까지 갈 수 있습니다.

### 1-2. 시작하기 전에 알아둘 것

앞으로 검은 화면에 글자를 입력하는 작업이 나옵니다. 그 화면의 이름이
**터미널**(내 컴퓨터에 글자로 명령을 내리는 창)입니다. 여는 방법은 환경에 따라
다릅니다.

- **맥 기본 터미널:** `Spotlight`(화면 우측 상단의 돋보기 아이콘, 또는
  `Cmd + Space` 키)를 누르고 `터미널`이라고 검색해 엽니다.
- **윈도우:** 화면 왼쪽 아래 시작 메뉴를 누르고 `PowerShell`이라고 검색해 엽니다.
  (윈도우의 터미널 이름이 `PowerShell`입니다.)
- **VS Code 안에서(경로 B):** VS Code 상단 메뉴에서 `Terminal` > `New Terminal`을
  누르면 창 아래쪽에 터미널이 열립니다.

아래 내용을 미리 알아 두시면 막히지 않습니다.

- 이 문서의 회색 코드블록을 **복사해서 터미널에 붙여넣고 엔터를 누르는 것**이
  곧 **명령어 실행**입니다. 외울 것도, 직접 타이핑할 것도 없습니다.
- 엔터를 누른 뒤 **검은 화면에 영어 글자가 쏟아지는 것은 정상입니다.** 오류가
  아닙니다. 프로그램이 지금 무슨 일을 하고 있는지 알려 주는 **로그**(진행
  기록)입니다.
- 붙여넣기 단축키는 맥이 `Cmd + V`, 윈도우 PowerShell은 `Ctrl + V`입니다.

### 1-3. 설치하고 준비할 것

| 준비물 | 필요한 경로 | 비용 |
| --- | --- | --- |
| 파이썬 3.9 이상 | 경로 A · B 공통 **(필수)** | 무료 |
| 텔레그램 계정 + **컴퓨터용 텔레그램 앱** | 경로 A · B 공통 **(필수)** | 무료 |
| 노션 계정 | 경로 A · B 공통 **(필수)** | 무료 요금제로 충분 |
| Git | 선택 (아래 설명 참조) | 무료 |
| VS Code | **경로 B를 고른 경우에만** | 무료 |

**파이썬**(이 프로그램을 실행해 주는 프로그램. 이런 것을 **런타임**이라고 합니다)은
양쪽 경로 모두 반드시 필요합니다.

- 다운로드: <https://www.python.org/downloads/>
- 이 봇은 **파이썬 3.9 이상**에서 동작합니다. (개발과 검증은 3.9.6에서 했습니다.
  더 높은 버전도 괜찮습니다.)
- ⚠️ **윈도우 설치 함정:** 설치 첫 화면 맨 아래의 **`Add python.exe to PATH`
  체크박스를 반드시 켜고** `Install Now`를 누르세요. 이 체크를 놓치면 터미널이
  파이썬을 찾지 못해 `python : 용어를 인식할 수 없습니다`라는 오류가 납니다.
  체크를 놓쳤다면 파이썬을 지우고 다시 설치하는 것이 가장 빠릅니다.

**컴퓨터용 텔레그램 앱**이 필요한 이유가 있습니다. 수식이나 목록이 들어간 정리
내용을 **휴대폰 텔레그램에서 보내면 서식 기호가 사라진 채 도착합니다.** 맥과
윈도우의 컴퓨터용 앱은 원문을 그대로 보내 줍니다. (자세한 내용은 §5-4)

- 다운로드: <https://desktop.telegram.org/>

**Git**(인터넷에 올라간 프로젝트 폴더를 내 컴퓨터로 내려받고 관리하는 프로그램)은
**필수가 아닙니다.** §4에서 프로젝트를 받는 방법을 두 가지 안내하는데, Git을 쓰는
방법이 더 간단합니다. 웹사이트에서 ZIP 파일로 받는 방법도 있으니, Git을 설치하고
싶지 않다면 그쪽을 쓰시면 됩니다.

- 다운로드: <https://git-scm.com/downloads>

**VS Code**(파일을 목록으로 보며 편집하는 프로그램)는 **경로 B를 고른 경우에만**
설치하세요. 경로 A에는 필요하지 않습니다.

- 다운로드: <https://code.visualstudio.com/>

**이 봇은 내 컴퓨터에서 돌아갑니다.** 컴퓨터를 켜 두고 터미널 창을 열어 둔 동안만
동작합니다. 자세한 내용은 §5-2에 있습니다.

## 📝 2. 노션 표 준비하기

봇이 기록을 적어 넣을 노션 표를 먼저 만들어야 합니다. 방법이 두 가지입니다.

| 방법 | 표 만들기 | 뷰(보는 화면) 만들기 | 권장 |
| --- | --- | --- | --- |
| **① 템플릿 복제** | 자동 | **자동** | ✅ 권장 |
| **② `setup_notion.py` 실행** | 자동 | 직접 만들어야 함 | 템플릿을 못 쓸 때 |

### 2-1. 방법 ① 템플릿 복제 (권장)

아래 링크를 열고 **우측 상단의 `복제`**(노션에서 `Duplicate`)를 누르면 내
작업공간에 표가 그대로 들어옵니다. 표의 구조는 물론 §2-4에서 설명하는 보는
화면까지 함께 복제되므로, 추가로 만들 것이 없습니다.

> 📋 노션 템플릿 복제 링크: https://trail-donkey-e6b.notion.site/3db567f259f58008bac3d5be860d515b?source=copy_link

복제가 끝나면 **§2-5의 통합 연결**로 넘어가세요.

### 2-2. 방법 ② `setup_notion.py`로 표 만들기

템플릿 링크를 쓸 수 없을 때 사용합니다. 이 방법은 **설치가 끝난 뒤**(§4의 ④번
의존성 설치까지 끝낸 뒤) 실행하는 것이라, 지금은 "이런 방법도 있다"만 알아 두고
§3으로 넘어가셔도 됩니다.

실행하면 표가 자동으로 만들어지고, 만들어진 표의 주소(ID)가 `.env` 파일에
자동으로 적힙니다.

```bash
python setup_notion.py
```

이 스크립트는 실행 중에 **표를 어느 페이지 아래에 만들지 번호로 고르라고 물어
봅니다.** 통합이 접근할 수 있는 노션 페이지 목록이 번호와 함께 나타나므로, 원하는
페이지의 번호를 입력하고 엔터를 누르면 됩니다.

⚠️ **이 방법으로 만든 표에는 보는 화면(뷰)이 기본 테이블 하나만 있습니다.**
§2-4를 보고 직접 만들어 주셔야 단원별·오답유형별로 모아 볼 수 있습니다.
표를 이미 만든 뒤에 이 스크립트를 다시 실행하면 `이미 표가 등록되어 있습니다`라고
알려 주고 아무것도 하지 않으므로, 실수로 표가 두 개 생기지는 않습니다.

### 2-3. 표의 구조 (속성 10개)

봇이 기록할 때 쓰는 칸입니다. 템플릿을 복제했거나 `setup_notion.py`를 실행했다면
이미 다 만들어져 있습니다. **무엇이 어디에 들어가는지 알아 두는 용도로만 보세요.**

| # | 속성(칸) 이름 | 타입 | 누가 채우나 |
| --- | --- | --- | --- |
| 1 | `개념명` | 제목(Title) | 봇이 `대표태그 · 문제위치` 형식으로 자동 조합 |
| 2 | `과목` | 선택(Select) | 봇 (버튼으로 고른 값) |
| 3 | `단원` | 선택(Select) | 봇 (`대분류-단원` 형태로 자동 결합) |
| 4 | `개념태그` | 다중 선택(Multi-select) | 봇 (여러 개 선택 가능) |
| 5 | `지식유형` | 선택(Select) | 봇 (버튼으로 고른 값) |
| 6 | `오답유형` | 다중 선택(Multi-select) | 봇 (건너뛸 수 있음) |
| 7 | `교재구분` | 선택(Select) | 봇 (건너뛸 수 있음) |
| 8 | `문제위치` | 텍스트(Text) | 봇 (직접 입력한 값) |
| 9 | `참고출처` | 텍스트(Text) | 봇 (직접 입력한 값) |
| 10 | `기록일` | 생성 일시(Created time) | 노션이 자동 |

정리 내용 원문은 속성이 아니라 **페이지 본문**으로 들어갑니다.

**선택형 칸의 선택지 목록**입니다. 봇은 켜질 때 노션에서 이 목록을 읽어 버튼을
만듭니다.

- `지식유형` (6개): `기준서` `법령` `이론·개념` `산식` `암기` `견해`
- `오답유형` (7개): `개념 미숙지` `개념 혼동` `조건 오독` `계산 실수`
  `함정 미인지` `시간부족` `근거오류`
- `교재구분` (5개): `기출` `객관식` `연습서` `모의고사` `AI질의`
- `과목` · `단원` · `개념태그`: **비어 있는 것이 정상입니다.** 봇이 처음 기록을
  저장하는 순간 노션이 자동으로 만들어 줍니다. **직접 입력하지 마세요.**

바꿔도 되는 것과 바꾸면 안 되는 것이 나뉩니다. 뭉뚱그리면 안전한 변경까지
겁내게 되므로 나누어 적습니다.

- ✅ **선택지 이름·색깔·순서는 자유롭게 바꾸셔도 안전합니다.** `오답유형`에
  `단위 실수`를 추가하거나, `지식유형`의 이름을 내 분류 취향대로 고쳐도 저장은
  깨지지 않습니다. 노션에 없는 선택지가 들어오면 노션이 알아서 만들어 줍니다.
  바꾼 것을 봇 버튼에도 반영하려면 **봇을 껐다 켜면** 됩니다(§8-2).
- ⚠️ **속성(칸) 이름과 타입은 절대 바꾸지 마세요.** `오답유형`을 `오답 유형`으로
  한 칸 띄우거나 `선택`을 `텍스트`로 바꾸면 **저장이 실패합니다.** 봇은 이
  이름을 글자 단위로 찾아 값을 넣기 때문입니다. 원인을 찾기가 매우 어려운
  종류의 고장이므로 손대지 않는 것이 좋습니다.
- ⚠️ `단원`과 `개념태그`의 선택지를 손으로 지우면, 그 값을 쓰고 있던 기존 기록의
  분류가 함께 사라집니다.

### 2-4. 보는 화면(뷰) 5개 — 방법 ②로 표를 만든 경우에만

템플릿을 복제했다면 이미 들어 있으니 이 항목은 넘어가세요.

노션 표 상단의 뷰 이름 옆 `+`를 눌러 아래 5개를 만듭니다.

| 뷰 | 형식 | 설정 |
| --- | --- | --- |
| ① 단원별 (기본) | **보드(Board)** | 필터 `과목` = 해당 과목 / 하위 그룹화(가로 레인) `단원` / 그룹화(세로 열) `개념태그` / `빈 그룹 숨기기` 켜기 |
| ② 과목별 | 테이블 | 그룹화 `과목` / 행 정렬 `기록일` 내림차순 |
| ③ 문제별 | 테이블 | 그룹화 `문제위치` / 필터 `문제위치`가 비어 있지 않음 |
| ④ 오답유형별 | 테이블 | 그룹화 `오답유형` |
| ⑤ 최근 기록 | 테이블 | 그룹화 없음 / 정렬 `기록일` 내림차순 |

⚠️ **그룹이 있는 모든 뷰에서 그룹 정렬을 `알파벳순`으로 두세요.** `수동`으로 두면
필터가 `과목=회계`인데도 다른 과목의 단원이 화면에 섞여 나타나고, 새로 만들어진
단원이 한동안 보이지 않습니다. 자세한 증상과 해결은 §7 트러블슈팅에 있습니다.

①번 뷰는 과목마다 하나씩 따로 만드는 것을 권합니다. `빈 그룹 숨기기`를 켜지 않으면
다른 단원의 태그 열까지 전부 표시되어 화면이 아주 넓어집니다.

### 2-5. 표에 통합 연결하기 (⚠️ 가장 많이 빠뜨리는 단계)

노션 표를 만들었다고 해서 봇이 그 표를 볼 수 있는 것은 아닙니다. **표마다 "이
프로그램의 접근을 허락한다"고 따로 지정해 주어야 합니다.** 이 지정을 노션에서
**통합**(Integration, 외부 프로그램이 내 노션에 접근할 수 있게 만든 출입증)
연결이라고 부릅니다.

통합은 §3-2에서 만듭니다. 통합을 먼저 만든 뒤 이 단계를 하세요.

1. 노션에서 학습 기록 표가 있는 페이지를 엽니다.
2. **우측 상단의 `···`** 버튼을 누릅니다.
3. **`연결`**(영문 노션은 `Connections`)을 누릅니다.
4. §3-2에서 만들어 둔 통합의 이름을 찾아 누릅니다.
5. 확인 창이 뜨면 `확인`을 누릅니다.

이 단계를 빠뜨리면 봇이 `404` 오류를 내고 표를 찾지 못합니다. 봇이 내는 오류
메시지에도 이 단계를 안내하도록 되어 있습니다.

### 3-1. 텔레그램 봇 토큰 — `TELEGRAM_BOT_TOKEN`

내 봇을 새로 만들고 그 열쇠를 받습니다. 텔레그램 앱 안에서 전부 끝납니다.

1. 텔레그램 검색창에 `BotFather`를 입력해 찾습니다. (이름 옆에 파란 체크가 있는
   공식 계정입니다.)
2. 대화창을 열고 `/newbot`을 보냅니다.
3. 봇의 **표시 이름**을 물어봅니다. 원하는 이름을 아무렇게나 보내세요.
   (예: `내 오답노트`)
4. 봇의 **사용자명**을 물어봅니다. 이 값은 **반드시 `bot`으로 끝나야 하고,
   이미 쓰이는 이름이면 거절됩니다.** 거절되면 다른 이름을 보내면 됩니다.
   (예: `my_wrongnote_2026_bot`)
5. 성공하면 `Use this token to access the HTTP API:` 아래에
   `숫자:영문숫자` 형태의 긴 글자열이 나옵니다. **이것이 봇 토큰입니다.**
   길게 눌러 복사해 두세요.

성공 신호: 위 메시지에 내 봇의 주소(`t.me/...`)가 함께 나타납니다. 그 주소를 눌러
대화창을 열어 두면 §3-3과 §5에서 바로 쓸 수 있습니다.

### 3-2. 노션 통합 토큰 — `NOTION_TOKEN`

1. 웹브라우저에서 <https://www.notion.so/my-integrations> 로 들어갑니다.
   (노션에 로그인된 상태여야 합니다.)
2. **`새 API 통합`**(영문은 `New integration`) 버튼을 누릅니다.
3. **이름**을 적습니다. 내가 알아볼 수 있으면 됩니다. (예: `오답노트봇`)
4. **연관된 워크스페이스**에서 내 노션 작업공간을 고릅니다.
5. `저장`을 누릅니다.
6. 만들어진 통합 화면에서 **`내부 통합 시크릿`**(영문은
   `Internal Integration Secret`)의 `표시`를 눌러 값을 확인하고 복사합니다.
   `ntn_` 또는 `secret_`으로 시작하는 긴 글자열입니다.

⚠️ **토큰만 받아 두면 끝이 아닙니다.** §2-5로 돌아가 이 통합을 내 노션 표에
연결해 주세요. 이 단계를 빠뜨리는 것이 가장 흔한 실수입니다.

### 3-3. 내 텔레그램 숫자 ID — `TELEGRAM_ALLOWED_USER_ID`

이 봇은 **여기에 적은 사람 한 명에게만 응답합니다.** 다른 사람이 내 봇 주소를
알아내 말을 걸어도 아무 반응을 하지 않습니다. 발급받는 값이 아니라, 텔레그램이
내 계정에 붙여 둔 숫자를 확인해 적는 것입니다.

**확인 방법 — 봇이 직접 알려 줍니다.** 이 값은 §4의 설치를 마친 뒤에 확인하게
되므로, `.env`를 처음 채울 때는 아래처럼 **임시로 `0`을 넣어 두세요.**

```
TELEGRAM_ALLOWED_USER_ID=0
```

그 상태로 봇을 실행하고(§4의 ⑤번), 텔레그램에서 내 봇에게 `/new`를 보냅니다.
봇은 응답하지 않지만, **봇을 실행한 터미널 창에 아래와 같은 줄이 나타납니다.**

```
[경고] 허용되지 않은 사용자 접근 시도 - id=123456789, 이름=홍길동
```

`id=` 뒤의 숫자가 내 텔레그램 숫자 ID입니다. 이 숫자를 `.env`의
`TELEGRAM_ALLOWED_USER_ID=0`에서 `0` 대신 적고 저장한 뒤, **봇을 껐다
켜면**(터미널에서 `Ctrl + C`를 누르고 다시 실행) 봇이 나에게 응답합니다.

### 3-4. 노션 표 주소 — `NOTION_DB_ID`

**이 값은 비워 두고 시작하세요.** 봇을 켠 뒤 텔레그램에서 `/setup`을 보내면 접근할
수 있는 노션 표를 버튼으로 보여 주고, 고른 값을 `.env`에 자동으로 적어 줍니다.
노션 주소에서 32자리 글자열을 눈으로 세어 잘라내는 일을 하지 않아도 됩니다.

```
NOTION_DB_ID=
```

`setup_notion.py`(§2-2)로 표를 만든 경우에는 그 스크립트가 이미 이 값을 적어
두었으므로 `/setup`도 필요하지 않습니다.

<details>
<summary>직접 입력하고 싶을 때 (대안)</summary>

1. 노션에서 학습 기록 표를 엽니다.
2. 우측 상단 `···` → `링크 복사`를 누릅니다.
3. 복사한 주소는 이런 모양입니다.

```
https://www.notion.so/내작업공간/8f2c1d4e5a6b7c8d9e0f1a2b3c4d5e6f?v=...
```

물음표(`?`) 바로 앞의 마지막 토막, 즉 `8f2c...5e6f` 32자리가 표의 주소입니다.
주소에 표 제목이 붙어 있으면(예: `CPA-지식-OS-8f2c...`) 마지막 하이픈 뒤부터가
32자리입니다. 이 값을 `NOTION_DB_ID=` 뒤에 붙여넣습니다.

</details>

### 3-5. 비용

두 서비스 모두 **이 봇을 쓰는 데 돈이 들지 않습니다.** 텔레그램 봇 API는 무료이고,
노션은 개인 무료 요금제로 충분합니다. 노션 API에 초당 약 3회의 요청 제한이 있는데,
봇이 알아서 간격을 두고 요청하며 제한에 걸리면 기다렸다 다시 시도합니다.

#### ③ `.env` 파일 만들고 편집하기

**`.env`**는 토큰처럼 남에게 보여선 안 되는 값을 적어 두는 파일입니다.
**맨 앞의 점(`.`)은 "숨김 파일"이라는 뜻**이라, 파일 탐색기나 파인더에서는 잘
보이지 않습니다. 그래서 터미널로 만드는 것이 확실합니다.

이 프로젝트에는 빈 양식인 `.env.example`이 들어 있습니다. 이것을 복사해
`.env`라는 이름으로 만듭니다.

**맥/리눅스**

```bash
cp .env.example .env
```

**윈도우 (PowerShell)**

```powershell
copy .env.example .env
```

이제 이 파일을 열어 값을 채웁니다. 경로 A에는 VS Code가 없으므로 **운영체제에
기본으로 들어 있는 편집기**를 씁니다.

**맥** — 기본 `텍스트 편집기`로 엽니다.

```bash
open -e .env
```

**윈도우** — 기본 `메모장`으로 엽니다.

```powershell
notepad .env
```

파일이 열리면 아래 다섯 줄의 `=` 뒤를 채웁니다. 파일에는 설명 주석(`#`으로
시작하는 줄)이 함께 들어 있으니, 그 줄은 그대로 두고 값만 적으면 됩니다.

```
TELEGRAM_BOT_TOKEN=여기에_3-1에서_받은_봇_토큰
TELEGRAM_ALLOWED_USER_ID=0
NOTION_TOKEN=여기에_3-2에서_받은_노션_토큰
NOTION_DB_ID=
NOTION_EXPORT_DB_ID=
```

- ⚠️ **`=` 뒤에 공백을 넣지 마세요.** 따옴표로 감싸지도 마세요. 값만 그대로
  붙여넣습니다.
- `TELEGRAM_ALLOWED_USER_ID`는 지금은 `0`으로 두고, ⑤번에서 확인한 숫자로
  바꿉니다(§3-3).
- `NOTION_DB_ID`와 `NOTION_EXPORT_DB_ID`는 **비워 둡니다.** 봇이 채워 줍니다.

저장 단축키는 맥이 `Cmd + S`, 윈도우가 `Ctrl + S`입니다.

⚠️ **윈도우 메모장의 함정:** 메모장에서 `다른 이름으로 저장`을 하면 파일 이름이
`.env.txt`로 바뀌어 봇이 파일을 찾지 못합니다. 위처럼 `copy` 명령으로 미리 만든
`.env`를 `notepad .env`로 열어 **그냥 `Ctrl + S`로 저장하면** 이 문제가 생기지
않습니다. 혹시 `다른 이름으로 저장`을 쓰게 된다면, 저장 창 아래의 `파일 형식`을
**`모든 파일 (*.*)`**로 바꾸고 파일 이름을 `.env`로 적어야 합니다.

이 창은 **켜 둔 채로** 둡니다. 이제 남은 일은 두 가지입니다.

1. **내 숫자 ID 채우기** — 텔레그램에서 내 봇에게 `/new`를 보내고, 이 터미널 창에

   다시 켭니다.
2. **노션 표 고르기** — 텔레그램에서 `/setup`을 보내고 버튼으로 표를 고릅니다.
   고른 값이 `.env`에 자동으로 적힙니다. 그런 다음 `Ctrl + C`로 끄고 다시 켜면
   준비가 끝납니다.

두 가지가 끝나면 실행 화면이 아래처럼 바뀝니다.

```
[봇] 봇을 시작합니다.
   과목 4개 / 단원 102개를 chapters.yaml에서 읽었습니다.
   노션에서 옵션을 읽었습니다 — 지식유형 6 / 오답유형 7 / 교재구분 5
   허용 사용자 ID: 123456789
   텔레그램에서 /new 를 보내 시작하세요. (끄려면 이 창에서 Ctrl+C)
```

설치가 끝났습니다. 사용법은 §5로 가세요.

#### ③ `.env` 파일 만들고 편집하기

**`.env`**는 토큰처럼 남에게 보여선 안 되는 값을 적어 두는 파일입니다.
**맨 앞의 점(`.`)은 "숨김 파일"이라는 뜻**입니다. VS Code의 파일 목록에서는
숨김 파일도 그대로 보이므로 편집이 쉽습니다.

이 프로젝트에는 빈 양식인 `.env.example`이 들어 있습니다.

1. VS Code 왼쪽 파일 목록에서 **`.env.example`을 우클릭**합니다.
2. **`Copy`**를 누르고, 빈 곳에 **`Paste`**를 합니다.
   (`.env.example copy` 같은 파일이 하나 생깁니다.)
3. 새로 생긴 파일을 **우클릭 > `Rename`**하고 이름을 **`.env`**로 바꿔 엔터를
   누릅니다.

> 양식을 남겨 둘 필요가 없다면 `.env.example`을 바로 우클릭 > `Rename` >
> `.env`로 바꿔도 됩니다.

`.env`를 눌러 열고, 아래 다섯 줄의 `=` 뒤를 채웁니다. 파일에는 설명 주석(`#`으로
시작하는 줄)이 함께 들어 있으니, 그 줄은 그대로 두고 값만 적으면 됩니다.

```
TELEGRAM_BOT_TOKEN=여기에_3-1에서_받은_봇_토큰
TELEGRAM_ALLOWED_USER_ID=0
NOTION_TOKEN=여기에_3-2에서_받은_노션_토큰
NOTION_DB_ID=
NOTION_EXPORT_DB_ID=
```

- ⚠️ **`=` 뒤에 공백을 넣지 마세요.** 따옴표로 감싸지도 마세요. 값만 그대로
  붙여넣습니다.
- `TELEGRAM_ALLOWED_USER_ID`는 지금은 `0`으로 두고, ⑤번에서 확인한 숫자로
  바꿉니다(§3-3).
- `NOTION_DB_ID`와 `NOTION_EXPORT_DB_ID`는 **비워 둡니다.** 봇이 채워 줍니다.

저장 단축키는 맥이 `Cmd + S`, 윈도우가 `Ctrl + S`입니다. 파일 이름 옆의 흰 점이
사라지면 저장된 것입니다.

#### ④ 가상환경 만들고 부품 설치하기

VS Code 아래쪽 터미널에서 진행합니다. **가상환경**은 이 프로젝트만 쓰는 독립된
작업실입니다. 여기에 부품을 설치하면 내 컴퓨터의 다른 파이썬 프로그램과 서로
충돌하지 않습니다.

**1) 가상환경 만들기** (맥·윈도우 공통. 처음 한 번만 합니다.)

```bash
python -m venv .venv
```

> 맥에서 `python: command not found`가 나오면 `python` 대신 `python3`을 쓰세요.
> (`python3 -m venv .venv`) 이후 명령어도 마찬가지입니다.

**2) 가상환경에 들어가기 — 맥/리눅스**

```bash
source .venv/bin/activate
```

**3) 가상환경에 들어가기 — 윈도우 (PowerShell)**

```powershell

```

성공 신호: 터미널 줄 맨 앞에 **`(.venv)`**가 나타납니다.

> ⚠️ 윈도우에서 `이 시스템에서 스크립트를 실행할 수 없으므로...`라는 **보안 오류**가
> 나면 §7 트러블슈팅의 첫 줄을 보세요. 명령어 한 줄로 해결됩니다.
>
> 💡 VS Code가 `Select Python Interpreter` 알림을 띄우면 `.venv`를 고르면 됩니다.
> 고르지 않아도 위 명령어로 직접 들어갔으므로 문제는 없습니다.

**4) 부품 설치하기** — 이 프로그램이 돌아가려면 함께 깔려 있어야 하는 부품들을
**의존성**이라고 합니다. 목록이 `requirements.txt`에 적혀 있습니다.

```bash
pip install -r requirements.txt
```

성공 신호: 마지막에 `Successfully installed ...`가 나옵니다. 영어 글자가 많이
쏟아지는 것은 정상입니다.

## 💡 5. 사용법

### 5-1. 봇 켜기

프로젝트 폴더에서 가상환경에 들어간 뒤 실행합니다.

```bash
python bot.py
```

끄는 방법은 그 터미널 창에서 **`Ctrl + C`**(실행 중인 프로그램을 강제로 끄는
단축키)입니다. 맥에서도 `Cmd`가 아니라 `Ctrl`입니다.

### 5-2. ⚠️ 봇이 어디서 돌아가는지 (오해 예방)

**이 봇은 인터넷의 어딘가가 아니라 내 컴퓨터에서 돌아갑니다.**

- **터미널 창을 닫거나 컴퓨터를 끄면 봇도 즉시 멈춥니다.** 그동안 텔레그램에서
  `/new`를 보내도 아무 응답이 없습니다.
- 멈춰 있는 동안 보낸 메시지는 사라지지 않습니다. **봇을 다시 켜면 밀려 있던
  메시지를 이어서 처리합니다.**
- 컴퓨터가 잠들면 함께 멈출 수 있습니다. 길게 쓸 때는 절전 설정을 확인하세요.
- 24시간 언제든 쓰고 싶다면 항상 켜져 있는 컴퓨터가 필요합니다. 이런 식으로 남의
  컴퓨터를 빌려 프로그램을 늘 돌려 두는 것을 **호스팅**이라고 합니다. 이
  프로젝트는 내 컴퓨터에서 돌리는 것을 전제로 만들어져 있어, 호스팅은 별도로
  알아보셔야 합니다.
- **입력하던 내용은 시간이 지나도 사라지지 않습니다.** 봇이 켜져 있는 동안에는
  중간에 멈췄던 입력을 그대로 이어서 할 수 있습니다. 그만두고 싶으면 화면의
  `[❌ 처음부터]`를 누르면 됩니다.

### 5-3. 명령어 4개

텔레그램 대화창에서 씁니다.

| 명령어 | 무엇을 하나 | 거치는 화면 |
| --- | --- | --- |
| `/new` | 오답 기록 한 건을 만들어 노션에 저장합니다 | **10단계** |
| `/export` | 기록을 모아 하나의 정리본으로 만듭니다 | 3~5개 |
| `/setup` | 저장할 노션 표를 버튼으로 고릅니다 | 2개 |
| `/raw` | 서식이 깨질 때 원인을 확인하는 진단 도구입니다 | 1개 |

세 가지 흐름(`/new` `/export` `/setup`)은 **동시에 진행할 수 없습니다.** 하나를
진행하는 중에 다른 명령어를 보내면 봇이 그 사실을 알려 주고 아무 일도 하지
않습니다. 진행 중인 화면을 끝내거나 `[❌ 취소]`를 누른 뒤 다시 보내세요.

### 5-4. `/new` — 기록 한 건 저장하기 (10단계)

`/new`를 보내면 화면 위에 `[1/10]`처럼 지금 몇 번째 단계인지 표시됩니다.
버튼을 누르며 진행하다가, 마지막에 정리 내용만 붙여넣으면 됩니다.

| 단계 | 무엇 | 입력 방법 | 건너뛰기 |
| --- | --- | --- | --- |
| 1/10 | 과목 | 버튼 | ✕ |
| 2/10 | 대분류 | 버튼 | ✕ |
| 3/10 | 단원 | 버튼 | ✕ |
| 4/10 | 개념태그 | 버튼 **(여러 개 가능)** | ✕ |
| 5/10 | 지식유형 | 버튼 | ✕ |
| 6/10 | 오답유형 | 버튼 (여러 개 가능) | ⏭ 가능 |
| 7/10 | 교재구분 | 버튼 | ⏭ 가능 |
| 8/10 | 문제위치 | **직접 입력** | ⏭ 가능 |
| 9/10 | 참고출처 | **직접 입력** | ⏭ 가능 |
| 10/10 | 정리 내용 | **직접 입력** | ✕ (필수) |

모든 화면에 `[⬅️ 뒤로]`(한 단계 되돌리기)와 `[❌ 처음부터]`(입력을 버리고 종료)가
있습니다. 건너뛸 수 있는 단계에는 `[⏭ 건너뛰기]`가 함께 나옵니다. 건너뛴 칸은
노션에서 빈 채로 남습니다.

#### 4단계 개념태그 — 여러 개 고르고, 대표를 하나 정합니다

지금 고른 태그는 버튼이 아니라 **본문 글자로** 표시되고, 버튼에는 아직 고르지
않은 태그만 남습니다. 태그 이름 옆의 숫자는 **그 단원에서 이 태그를 지금까지 몇
번 썼는지**입니다.

- `[✔️ 선택 완료]` — 고르기를 끝내고 다음 단계로 갑니다.
- `[➕ 새 태그]` — 목록에 없는 태그를 직접 입력해 만듭니다. 만든 태그는 바로
  선택된 상태가 됩니다. **쉼표(`,`)로 나누어 여러 개를 한 번에 넣을 수
  있습니다.** ⚠️ 태그 **이름 자체에는 쉼표를 쓸 수 없습니다.** 노션이 거부합니다.
- `[🔍 검색]` — 글자 일부를 입력하면 그 단원의 태그 중 그 글자가 들어간 것만
  남습니다. `[🔎 검색 해제]`로 전체 목록으로 돌아갑니다.
- `[🗑 태그 빼기]` — 잘못 고른 태그를 뺍니다.
- `[⭐ 대표 바꾸기]` — 고른 태그 중 하나를 **대표**로 지정합니다. 대표 태그는
  본문에 `⭐`로 표시되며, **노션 페이지의 제목에 쓰입니다.** 기본값은 처음 고른
  태그이므로 대개 손댈 필요가 없습니다. 태그를 하나만 골랐다면 그것이 대표입니다.

노션 제목은 `대표태그 · 문제위치` 형식으로 자동 조합됩니다. 문제위치를
건너뛰었으면 `대표태그 · MM/DD`(월/일)가 됩니다.

#### 8단계 문제위치 vs 9단계 참고출처 — 성격이 다릅니다

- **문제위치**는 "이 **문제**가 어디 있었나"입니다. 형식: `연p.212#15`
  접두어는 `연`=연습서 `객`=객관식 `기`=기출 `모`=모의고사입니다.
  ⚠️ **같은 문제는 표기를 글자 하나까지 똑같이 적어야** 노션의 `③ 문제별` 뷰에서
  한 묶음으로 모입니다. `연p.21-3#기01`과 `연p.21-3#기1`은 다른 문제로 취급됩니다.
- **참고출처**는 "이 **개념**의 근거가 어디 있나"입니다. 형식을 강제하지 않습니다.
  예: `기준서 1116호 문단 22` · `부가가치세법 제29조 제3항` · `워p.131`

수식·목록·코드블록 같은 **서식이 들어간 정리 내용은 반드시 컴퓨터(맥·윈도우)
텔레그램에서 보내세요.** 휴대폰(iOS)에서 보내면 텔레그램이 `$$` `##` `- `
`\`(역슬래시) 같은 서식 기호를 **지운 채로** 전송합니다. 지워진 기호는 되살릴 수
없어 내용이 반쪽만 저장됩니다.

| 보내는 곳 | 서식 보존 | 판정 |
| --- | --- | --- |
| 맥 데스크톱 앱 | 원문 그대로 | ✅ 안전 |
| 윈도우 데스크톱 앱 | 원문 그대로 | ✅ 안전 |
| 휴대폰 (iOS) | 기호가 지워짐 | ❌ 위험 |

> 윈도우 앱에서 붙여넣을 때 `Pasted as plain text`라는 안내가 뜹니다. 이것은
> **정상이며 안전합니다.** 서식 없이 붙여넣었다고 알려 주는 것일 뿐, 글자를
> 지우지는 않습니다.

**서식이 전혀 없는 짧은 글은 휴대폰에서 보내도 문제없습니다.**

봇에는 안전망이 하나 더 있습니다. 도착한 글에서 서식이 깨진 흔적이 발견되면
저장하지 않고 먼저 물어봅니다. 이때 입력한 내용은 그대로 남아 있으므로,
`[🔁 그래도 저장]`을 누르면 받은 그대로 저장되고 `[❌ 취소]`를 누르면 버립니다.
다만 이 감지는 흔한 사고를 막는 장치일 뿐, 모든 경우를 잡아내지는 못합니다.

#### 정리 내용 작성 규격

봇이 알아보는 서식은 아래 여섯 가지입니다. 이 외의 표기(굵게, 기울임, 인용,
마크다운 표, 문장 중간에 넣는 수식)는 **처리하지 않으므로 쓰지 마세요.**

| 이렇게 적으면 | 노션에 이렇게 들어갑니다 |
| --- | --- |
| `$$`로 시작해 `$$`로 끝나는 구간 | 수식 블록 |
| `:::code 언어` ~ `:::` 구간 | 코드 블록 |
| `## `로 시작하는 줄 | 중제목 |
| `- `로 시작하는 줄 | 글머리 목록 (공백 2칸 들여쓰면 하위 항목) |
| `1. `로 시작하는 줄 | 번호 목록 |
| 그 외의 줄 | 보통 문단 |

⚠️ **네 가지를 꼭 지켜 주세요.** 지키지 않으면 내용이 조용히 사라지거나 저장이
실패합니다.

1. **수식 안에서만 퍼센트를 `\%`로 씁니다.** 수식(`$$ ... $$`) 안에서 `%`를 그냥
   쓰면 **그 줄의 나머지가 오류도 없이 사라집니다.** 반대로 **수식 밖의 평범한
   문장이나 목록에서는 그냥 `%`를 쓰세요.** 밖에서 `\%`를 쓰면 노션에 역슬래시가
   그대로 보입니다.
2. **수식 안의 한글은 `\text{}`로 감쌉니다.**
   예: `\frac{\text{과세공급가액}}{\text{총공급가액}}`
3. **목록 중첩은 두 겹까지만** 씁니다. 세 겹째를 보내면 노션이 거부해 저장이
   실패합니다.
4. 제목은 **`## `**(뒤에 공백 포함)를 씁니다. `#` 하나만 쓰면 텔레그램이
   해시태그로 인식해 버립니다.

작성 예시입니다.

```
## 공통매입세액 재계산

- 재계산 대상: 감가상각자산만
  - 건물·구축물은 10%씩, 그 밖의 자산은 25%씩 체감
- 과세비율이 5% 이상 변동해야 재계산합니다

$$
\text{재계산세액} = \text{매입세액} \times (1 - 0.05 \times \text{경과과세기간})
$$

$$
\text{증감비율} = \frac{\text{과세공급가액}}{\text{총공급가액}} - \text{직전비율}
$$
```

#### 저장한 뒤

저장이 끝나면 아래 화면이 나옵니다.

```
✅ 저장 완료
⚠️ #가산세중복적용배제 4번째 · #세금계산서불성실 2번째

[🔗 노션에서 보기]
[📌 같은 문제로 하나 더]  [🏁 종료]
```

- `⚠️` 줄은 **같은 태그를 두 번 이상 쓴 경우에만** 나옵니다. 이 개념을 몇 번째
  틀렸는지 알려 주는 경고입니다. 처음 쓰는 태그만 골랐다면 `✅ 저장 완료`만
  나옵니다.
- `[🔗 노션에서 보기]`로 열리는 페이지는 **항상 최신 상태입니다.**
- `[📌 같은 문제로 하나 더]` — 한 문제에서 여러 개념이 나왔을 때 씁니다.
  **과목 · 대분류 · 단원 · 교재구분 · 문제위치를 그대로 이어서 쓰고**,
  개념태그 선택 화면(4단계)부터 다시 시작합니다. 문제위치를 다시 묻지 않는 것은
  일부러 그렇게 만든 것입니다. 다시 물으면 같은 문제인데도 표기가 갈려 노션의
  `③ 문제별` 뷰에서 한 묶음으로 모이지 않습니다. 표기를 바꿔야 할 때는 그 화면의
  `[✏️ 출처 바꾸기]`를 누르세요.

#### 저장에 실패했다면

인터넷이 끊기는 등의 이유로 노션 저장이 실패하면, 봇은 **입력한 내용을 내 컴퓨터의
`pending_records.json` 파일에 보관합니다.** 내용이 사라지지 않습니다. 그 자리에서
`[🔄 다시 시도]`를 누를 수도 있고, 그냥 두었다가 나중에 봇을 다시 켜면
`저장하지 못한 기록이 1건 있습니다`라는 알림이 옵니다. 거기서 `[🔄 지금 저장]`을
누르면 노션에 올라가고, `[🗑 버리기]`를 누르면 버립니다.

### 5-5. `/export` — 기록을 하나의 정리본으로 모으기

시험 직전에 원하는 범위의 기록을 한 번에 읽으려고 만든 기능입니다. 노션 자체
내보내기는 페이지마다 파일이 따로 생겨 이 목적에 맞지 않습니다.

1. `/export`를 보냅니다.
2. **과목**을 버튼으로 고릅니다.
3. **범위**를 고릅니다 — `📚 과목 전체` / `📂 단원으로 좁히기` /
   `🏷 개념태그로 좁히기`
4. 단원으로 좁히면 대분류와 단원을, 개념태그로 좁히면 태그를 고릅니다.
5. 봇이 해당 기록을 모읍니다. 건수가 많으면 `12건 중 5건 수집 중...`처럼
   진행 상황을 알려 줍니다.
6. 다 모으면 받는 방법을 묻습니다.

```
✅ 12건을 모았습니다.
[📥 파일로 받기]   [📄 노션에 저장]
```

- **`[📄 노션에 저장]`을 권합니다.** 정리본은 수십 건을 합친 것이라 텔레그램
  메시지 길이 제한을 거의 확실히 넘습니다. 노션에 저장하면 **추출본 표**라는
  별도의 표가 자동으로 만들어지고(처음 한 번만), 거기에 정리본 페이지가 쌓입니다.
  이 표의 주소는 `.env`의 `NOTION_EXPORT_DB_ID`에 자동으로 적힙니다.
  **학습 기록 표와 섞이지 않습니다.**
- `[📥 파일로 받기]`를 누르면 **읽기용 마크다운 파일**을 텔레그램으로 보내 줍니다.
  ⚠️ 이 파일을 **봇에게 다시 보내도 저장되지 않습니다.** 읽기 위한 파일입니다.

고른 범위에 기록이 하나도 없으면 그 사실을 알려 주고 끝냅니다.

### 5-6. `/setup` — 저장할 노션 표 고르기

`.env`의 `NOTION_DB_ID`를 채우는 가장 쉬운 방법입니다(§3-4).

1. `/setup`을 보냅니다. 봇이 통합이 접근할 수 있는 노션 표를 찾습니다.
2. 표 목록이 버튼으로 나타납니다. 쓰려는 표를 누릅니다.
3. 고른 표의 주소가 `.env`에 자동으로 적힙니다.
4. **봇을 껐다 켜면** 그 표에 저장하기 시작합니다.

표가 하나도 나오지 않는다면 §2-5의 통합 연결을 하지 않은 것입니다. 봇이 그
경우에도 무엇을 확인해야 하는지 안내합니다. 이 명령은 **읽기와 `.env` 기록만
하며, 노션에 아무것도 쓰거나 지우지 않습니다.**

### 5-7. `/raw` — 서식 진단 도구

정리 내용의 서식이 깨져 저장될 때, **어디서 깨졌는지 확인하는 도구**입니다.
`/raw`를 보낸 뒤 다음 메시지를 보내면, 봇이 도착한 글자를 그대로 뜯어 `$$`가 몇
개인지, 역슬래시가 몇 개 살아 있는지 등을 보여 줍니다.

**기록을 남기는 명령이 아닙니다.** 여기로 보낸 글은 노션에 저장되지 않습니다.

## 🧑‍💻 8. 커스텀 안내

### 8-1. 과목·단원 추가하기 — `chapters.yaml`만 고치면 됩니다

봇의 과목·대분류·단원 버튼은 전부 `chapters.yaml` 파일 하나에서 만들어집니다.
코드는 건드릴 필요가 없습니다.

#### 파일 여는 법

`chapters.yaml`은 **글자만 들어 있는 파일**이라, 컴퓨터에 원래 깔려 있는 메모장으로 열 수 있습니다. 따로 설치할 프로그램은 없습니다.

- **맥**: 프로젝트 폴더에서 `chapters.yaml`을 우클릭 → `다음으로 열기` → `텍스트 편집기`
- **윈도우**: `chapters.yaml`을 우클릭 → `연결 프로그램` → `메모장`
(더블클릭하면 "이 파일을 열 앱을 선택하세요" 창이 뜰 수 있는데, 거기서 `메모장`을 고르셔도 됩니다)
- **VS Code를 쓰신다면** 그냥 VS Code로 여시면 됩니다. 들여쓰기가 틀렸을 때 색으로 알려주어 가장 편합니다.

⚠️ **한글(HWP)이나 워드(Word)로는 절대 열지 마세요.** 눈에 보이지 않는 서식이 섞여 들어가 파일이 망가지고, 봇이 켜지지 않습니다.

#### 파일 구조

파일을 열면 맨 위에 수정 방법이 주석으로 적혀 있고, 그 아래로 아래와 같은 형식이 이어집니다.

```yaml
세법:
  부가가치세:
    - ch06.매입세액과 납부세액
    - ch07.겸영사업자 세액계산
```

`과목:` → `대분류:` → `- 단원` 세 계층입니다. 노션에는 `대분류-단원` 형태로 저장됩니다.
내가 사용하는 교재 목차에 맞게 고치거나 과목을 새로 추가하세요.

#### ⚠️ 지킬 것 네 가지

1. **들여쓰기는 공백 2칸 단위입니다. 탭(`Tab`) 키를 쓰면 안 됩니다.**
스페이스바를 두 번 눌러 띄우세요. 위 예시에서 `부가가치세:` 앞은 공백 2칸, `ch06...` 앞은 공백 4칸입니다. 이게 어긋나면 봇이 켜지지 않고 "chapters.yaml 형식이 잘못되었습니다"라는 안내가 나옵니다.
2. **장 번호는 두 자리로 적습니다.** (`제1장` ✕ → `제01장` ✅)
한 자리로 적으면 노션에서 `제1장 → 제10장 → 제2장` 순으로 정렬이 어긋납니다.
3. **단원 이름에 콜론(`:`)을 넣으려면 따옴표로 감싸세요.**
4. **저장할 때 파일 이름이 바뀌지 않았는지 확인하세요.**
윈도우 메모장은 저장 시 `chapters.yaml.txt`로 이름을 바꿔 버리는 경우가 있습니다. 저장 창에서 `파일 형식`을 `모든 파일`로 바꾼 뒤 이름을 `chapters.yaml` 그대로 적어 저장하세요.
(이미 있는 파일을 열어서 `Ctrl + S`로 덮어쓰면 이 문제가 생기지 않습니다)

#### 고친 뒤에는

봇을 껐다 켜야 반영됩니다. (`Ctrl + C` 후 `python bot.py`)

이미 노션에 저장된 기록의 단원 이름을 여기서 바꿔도, 기존 노션 기록은 예전 이름 그대로 남습니다. 자동으로 바뀌지 않으니 노션에서 따로 정리해야 합니다.

### 8-2. 노션 선택지 바꾸기 — 노션에서 바꾸면 됩니다

`지식유형` `오답유형` `교재구분`의 선택지는 **노션 화면에서 바꾸세요.** 코드를
고칠 필요가 없습니다. 봇은 켜질 때 노션에서 이 목록을 읽어 버튼을 만듭니다.

- 선택지를 추가·삭제·이름 변경·색깔 변경 모두 **안전합니다**(§2-3).
- **바꾼 뒤 봇을 껐다 켜면** 버튼에 반영됩니다.
- ⚠️ 한 속성의 선택지를 **전부 지우면 봇이 버튼을 만들 수 없어** 켜지지 않고
  안내 후 종료합니다. 최소 하나는 남겨 두세요.
- ⚠️ **속성(칸) 이름과 타입은 바꾸지 마세요**(§2-3). 이쪽은 코드와의 약속입니다.

### 8-3. Claude Code로 고치기 (선택 사항)

**이 항목은 선택입니다.** Claude Code는 자연어로 코드 수정을 부탁할 수 있는
도구인데, **별도의 구독이 필요할 수 있습니다.** 없어도 §8-1과 §8-2의 방법만으로
과목·단원과 선택지 커스텀은 모두 가능합니다.

**경로 A — 터미널에서 설치하기**

```bash
npm install -g @anthropic-ai/claude-code
```

프로젝트 폴더로 이동한 뒤 실행합니다.

```bash
claude
```

**경로 B — VS Code 확장으로 설치하기**

1. VS Code 왼쪽 막대에서 **`Extensions`**(네모 네 개 모양) 아이콘을 누릅니다.
2. 검색창에 `Claude Code`를 입력합니다.
3. Anthropic이 만든 확장을 찾아 `Install`을 누릅니다.

**공통 — 쓰는 방법**

1. 처음 실행하면 로그인을 안내합니다. 안내대로 로그인합니다.
2. 고치고 싶은 파일을 열어 둔 상태로 원하는 것을 한국어로 그냥 적습니다.

> 예: `chapters.yaml에 '원가' 과목을 추가하고 싶어. 대분류는 '원가회계'로,
> 단원은 제01장부터 제05장까지 만들어줘.`

3. **초보자는 변경을 매번 확인하고 승인하는 기본 모드를 그대로 쓰세요.** 무엇을
   고치려 하는지 보여 준 뒤 물어보므로 안전합니다.
4. 코드나 `chapters.yaml`을 고쳤다면 **봇을 껐다 켜야 반영됩니다.**

### 데이터가 저장되는 곳

- **학습 기록**은 내 노션 작업공간에만 저장됩니다. 이 프로젝트에는 어떤 서버도
  없고, 만든 사람도 내 기록을 볼 수 없습니다.
- **인증키**는 내 컴퓨터의 `.env` 파일에만 있습니다. `.gitignore`에 들어 있어
  깃허브에 올라가지 않습니다.
- **저장에 실패한 기록**은 내 컴퓨터의 `pending_records.json`에 임시 보관됩니다.
  개인 학습 내용이 들어가므로 이 파일도 `.gitignore`에 들어 있습니다.
- ⚠️ 실제 인증키를 깃허브에 올려 버렸다면, 파일을 지우는 것만으로는 부족합니다.
  **텔레그램 BotFather와 노션 통합 페이지에서 그 키를 폐기하고 새로 발급받으세요.**
